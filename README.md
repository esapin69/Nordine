# Charge.

Application React de planification de charge et de suivi de séance de musculation.

## Fonctions

- Estimation du 1RM avec la formule d’Epley
- Programme progressif vers un objectif
- Visualisation des disques à charger
- Mode séance libre avec recommandation de charge
- Historique conservé localement sur l’appareil
- Installation possible sur l’écran d’accueil

## Lancer en local

```bash
npm install
npm run dev
```

## Publier

Le projet peut être importé directement dans Vercel ou Netlify. Pour GitHub Pages, exécuter `npm run build` puis publier le dossier `dist`.

Les données sont enregistrées uniquement dans le navigateur de chaque utilisateur. Elles ne sont ni partagées ni synchronisées entre appareils.
